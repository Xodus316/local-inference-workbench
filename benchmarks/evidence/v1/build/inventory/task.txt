Implement solution.py as a single-file Python standard-library CLI for atomic inventory allocation. Read exactly one JSON object from stdin and write one JSON object on success.

Input has required stock and orders fields. stock is an object mapping nonempty lowercase ASCII SKU names (a-z only) to nonnegative integer quantities; it may be empty. orders is an array, possibly empty. Every order is an object with required id, priority and items. id is a nonempty lowercase ASCII name and must be unique across orders. priority is any signed integer. items is a nonempty object mapping lowercase ASCII SKU names to strictly positive integer quantities. Booleans and floats never qualify as integers. Ignore extra root and order fields. Validate the whole input before allocating, including orders that would later be rejected. Malformed JSON, a non-object root, missing fields, invalid types/names/ranges or duplicate order IDs must exit nonzero with exactly empty stdout. Stderr is unspecified.

Process orders by descending priority, breaking ties by ascending lexicographic id, independent of input order. Fulfil an order only if every requested SKU has enough stock. An absent SKU has zero stock, so an order requesting it is rejected rather than considered invalid. Fulfilment deducts every requested quantity atomically. Rejection deducts nothing; stock must remain available to later orders. Continue processing after a rejection. Use exact integer arithmetic even for values larger than 2**53.

Output has exactly fulfilled, rejected and remaining. fulfilled and rejected are arrays of order IDs, each in processing order within that outcome. remaining is an array of [SKU, quantity] pairs sorted lexicographically by SKU. Preserve every original stock SKU, including those with zero remaining quantity, and never add unknown requested SKUs. Empty orders leave stock unchanged. JSON whitespace and object key order are immaterial. No importable API is promised; invoke python3 solution.py. Do not use external packages, network access or nondeterministic behavior.
