Create a single file python terminal cli. The goal of it is to accept JSON input with statistics of 2 starships. Each starship has hull value, shields on 4 arcs and weapons on each arc. Each weapon has a recharge time. The program will run a simulation of turn based combat between the 2 ships. The ships each fire at each other with all available weapons on the available arc. It ends when one ship is destroyed and the app returns the result of the battle.
