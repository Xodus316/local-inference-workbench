Plan a single-file Python standard-library CLI, solution.py, for splitting an indivisible pool of credits. Read one JSON object from stdin with credits (a nonnegative integer) and weights (a nonempty object mapping distinct lowercase ASCII letter-only IDs to nonnegative integers). Ignore extra top-level keys. JSON booleans and floats are invalid integers. The sum of weights must be positive, including when credits is zero. Assume JSON object member names are unique. There is no application-imposed bound on integer size. Use exact integer arithmetic throughout.

Give each ID the floor of its proportional share, then give one additional credit to each of the highest remainder IDs in order until all credits have been allocated. Break equal remainders by ascending ID, independent of input order. Include zero allocations. On success exit zero and write a JSON array of [ID, allocated_integer] pairs sorted by ascending ID. Invalid input, including malformed JSON, must exit nonzero with empty stdout. Stderr and JSON whitespace are unspecified. Include at least two concrete test inputs and their exact expected results, including one that exercises a remainder tie.
