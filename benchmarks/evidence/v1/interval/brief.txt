Write a Python 3 standard-library function solution.merge_ranges(rows). Input is a list of lists of exactly two integers each, [start, end], representing inclusive integer ranges. Negative and arbitrarily large integers are valid. Require start <= end. Booleans and floats are invalid. Raise ValueError for every invalid input, including wrong outer/inner types or malformed pairs. Accept an empty list. Return a sorted list of [start, end] lists giving the union, merging both overlaps and adjacent ranges (one ends exactly one less than the next starts). Never mutate the input, even on error. Support unsorted inputs, duplicates, one-point intervals, and containment. Runtime must depend on the number of intervals, not on the number of integer points covered. No CLI or dependencies.
